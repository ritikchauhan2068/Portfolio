Methodology

How I Approach Engineering Problems

From deconstructing messy business requirements to shipping tested, idempotent production services.

01

Understand Requirements

Dig into the operational root cause. For client projects, I interview end-users (e.g. diagnosing why shopkeeper handwritten bills created a 2+ hour daily ledger bottleneck for wholesalers).

Example: Wholesale Order Automation scoping
02

Architect & Model

Select the appropriate technology boundary. Keep providers swappable via clean interfaces (e.g. Vision-LLM vs Tesseract, Twilio vs WhatsApp Cloud API) and enforce data integrity at the database layer.

Example: Abstracting OrderExtractor interface
03

Implement Cleanly

Build modular FastAPI routers, service layers, and Pydantic schemas. Use cheap regex parsing first for standard commands ("remove X", "qty 5") before invoking costly LLM inference.

Example: Regex edit parsing with LLM fallback
04

Deploy & Optimize

Containerize with Docker, configure DNS and SSL certificates, deploy to cloud providers (DigitalOcean, Render), and profile endpoints to eliminate latency bottlenecks.

Example: 35% API latency optimization on Render
