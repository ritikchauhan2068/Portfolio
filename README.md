## 🛠️ Local Development & Running the Website

Because this is a pure modern static web application, you can run it with any lightweight web server:

### Option 1: Using Python (Recommended)
```bash
# Navigate to the portfolio folder
cd "C:\Users\User 2\.gemini\antigravity\scratch\ritik-portfolio"

# Start local server on port 8000
python -m http.server 8000
```
Then open your browser to [http://localhost:8000](http://localhost:8000).

### Option 2: Direct Browser Launch
You can also directly double-click `index.html` to open it in Google Chrome, Microsoft Edge, or Firefox.

## 🌐 Deployment Instructions

### Deploying to Netlify (Existing Setup)
Your previous portfolio was hosted on Netlify (`https://voluble-panda-3a9ee0.netlify.app/`):
1. **Option A (Netlify Drop - Fastest)**:
   - Go to [Netlify Drop](https://app.netlify.com/drop).
   - Drag and drop the `ritik-portfolio` folder directly into the browser window.
   - Netlify will deploy it in seconds with global CDN and SSL.
2. **Option B (Git / GitHub Push)**:
   - Commit the updated files to your GitHub repository `ritikchauhan2068/My-portfilo`.
   - Link the repository in Netlify dashboard with publish directory set to `/` or repository root.

### Deploying to GitHub Pages
1. Push this folder to your GitHub repository (e.g. `ritikchauhan2068/ritikchauhan2068.github.io` or `My-portfilo`).
2. In your GitHub repository, navigate to **Settings** → **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch** (select `main` branch and `/ (root)` folder).
4. Save, and your portfolio will be live at `https://ritikchauhan2068.github.io/`!
